# Original planet surface artwork

These five surface maps were generated specifically for this portfolio using the built-in image generation tool. They do not use downloaded third-party texture packs or reference images. They are artistic illustrations rather than scientific maps. The ring renderer is project-authored shader code.

The PNG files are original generated outputs and the active surface textures. The website maps the native lossless images onto rotating spheres, applies a restrained sharpening pass, and blends longitude boundaries at runtime. No external image service is contacted by the website.
